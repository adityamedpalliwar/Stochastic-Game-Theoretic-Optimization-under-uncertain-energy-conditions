Phase 8E: Stochastic Expected-Payoff Nash Equilibrium

Game-theoretic energy trading under renewable forecast uncertainty. Evaluates 1,000 synchronized Monte Carlo demand/solar scenarios with non-anticipative battery dispatch.

✓ Stochastic Engine Active
Ex-Ante Role-Conditioned Bidding (Option 1A)
Mathematical Modeling Formulation & Contract Specifications:
  • Option 1A Seven-Price Bidding: Active prosumers choose 1 action from discrete grid $\mathcal{P} = \{0.08, 0.12, 0.16, 0.19, 0.22, 0.26, 0.30\}$ AUD/kWh (ASK if ex-ante seller, BID if ex-ante buyer).
  • Option 2A Synchronized Uncertainty: 1,000 paired demand-solar scenarios generated via synchronized validation residual pool draws, preserving microgrid-wide weather correlation.
  • Option 3A Frozen Battery Dispatch: Adopts authoritative Phase 7.1 Stochastic MPC first-stage decisions ($C_0, B_0$) fixed across all scenarios for that hour.
  • Physical Role-Conflict Clamping: In scenarios where realized net flow opposes ex-ante role, the household submits no order ($q=0$). Inactive households submit no order.
  • Expected Payoff Integration: Expected payoffs $\mathbb{E}[U_i(a)] = \frac{1}{M}\sum_{s=1}^M U_i(a, \omega_s)$ are averaged strictly across all 1,000 scenarios (denominator $M=1,000$).
  • Academic Disclosure: This is a restricted ex-ante role-conditioned game, not a full two-sided contingent bidding game. For zero-trade hours, all 343 profiles yield identical zero payoffs and form weak equilibria.
