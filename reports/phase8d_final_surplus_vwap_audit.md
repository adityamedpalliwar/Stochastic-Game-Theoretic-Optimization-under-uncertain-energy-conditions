## 2. Mathematical Framework & Proof of Identity

In the residential microgrid double auction, prosumers trade energy within the fixed retail tariff band:
- Retail import tariff: $p_{\text{imp}} = 0.30\text{ AUD/kWh}$
- Solar export credit: $p_{\text{exp}} = 0.08\text{ AUD/kWh}$
- Retail unit spread: $\Delta p = p_{\text{imp}} - p_{\text{exp}} = 0.22\text{ AUD/kWh}$

### 2.1 Transaction-Level Payoff Definitions
Let the market clear in hour $t$ producing a set of cleared bilateral transactions $\mathcal{K}_t$. Each transaction $k \in \mathcal{K}_t$ transfers energy quantity $q_k > 0$ at cleared price $p_k \in [0.08, 0.30]$ from seller $s(k)$ to buyer $b(k)$.

The incremental economic surplus earned from transaction $k$ relative to the standalone grid benchmark is:
$$U_{\text{seller}, k} = q_k \times (p_k - p_{\text{exp}}) = q_k \times (p_k - 0.08)$$
$$U_{\text{buyer}, k} = q_k \times (p_{\text{imp}} - p_k) = q_k \times (0.30 - p_k)$$

The community welfare generated by transaction $k$ is:
$$\Delta W_k = U_{\text{seller}, k} + U_{\text{buyer}, k} = q_k \times (p_k - 0.08 + 0.30 - p_k) = 0.22 \times q_k$$

### 2.2 Macro-Level Aggregation & The VWAP Identities
Summing over all transactions across all hours $t = 1, \dots, 1752$:
$$Q = \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k$$
$$U_{\text{seller_total}} = \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k (p_k - 0.08) = \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k p_k - 0.08 \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k$$
$$U_{\text{buyer_total}} = \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k (0.30 - p_k) = 0.30 \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k - \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k p_k$$

By definition, the Volume-Weighted Average Price (VWAP) is:
$$\text{VWAP} = \frac{\sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k p_k}{\sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k} = \frac{1}{Q} \sum_{t=1}^{1752} \sum_{k \in \mathcal{K}_t} q_k p_k$$

Substituting $\sum q_k p_k = Q \times \text{VWAP}$ into the benefit sums yields the identities:
$$U_{\text{seller_total}} = Q \times (\text{VWAP} - 0.08)$$
$$U_{\text{buyer_total}} = Q \times (0.30 - \text{VWAP})$$
$$U_{\text{seller_total}} + U_{\text{buyer_total}} = Q \times (\text{VWAP} - 0.08 + 0.30 - \text{VWAP}) = 0.22 \times Q = \Delta W$$

These identities are exact mathematical truths in any double-auction market where individual transactions clear at bilateral prices $p_k$.

## 3. Independent Transaction-Level Reconstruction

To conduct this audit without relying on any pre-aggregated metrics, a clean independent Python script (`scratch_gen_table.py`) executed the following bottom-up procedure:
1. Iterated over all 1,752 hours in `reports/phase8c_all_equilibria.json.gz`.
2. For each evaluated strategy configuration, retrieved the selected Pareto equilibrium profile $(p_{\text{H001}}, p_{\text{H002}}, p_{\text{H003}})$.
3. Constructed discrete market orders with actual physical post-battery positions $(s_i, d_j)$ from `reports/phase8c_hourly_equilibria.csv`.
4. Cleared the strategic double auction using `clear_strategic_double_auction()` to obtain the exact set of bilateral transactions $\mathcal{K}_t = \{ (s, b, q_k, p_k) \}$.
5. Directly accumulated:
   - Total volume: $\sum q_k$
   - Total monetary turnover: $\sum q_k p_k$
   - Individual transaction seller benefit: $\sum q_k (p_k - 0.08)$
   - Individual transaction buyer benefit: $\sum q_k (0.30 - p_k)$
6. Computed transaction-reconstructed VWAP and evaluated residuals against reported CSV metrics and theoretical identities.

## 5. Root-Cause Analysis of the Historical Discrepancy

The audit conducted a detailed forensic review of the repository history to determine the exact origin of the erroneous figures reported in earlier draft iterations of Table 5.1:
- `Strategy A Seller Benefit: $13.568600 AUD (50.72%)`
- `Strategy B Seller Benefit: $16.422774 AUD (61.38%)`
- `Strategy C Seller Benefit: $8.066497 AUD (30.15%)`
- `Strategy D Seller Benefit: $12.392067 AUD (46.32%)`
- `Strategy E Seller Benefit: $12.964955 AUD (48.46%)`

### 5.1 Mathematical Impossibility of Historical Figures
If the historical seller benefit of $\$13.568600\text{ AUD}$ were correct for Strategy A, substituting into the VWAP identity:
$$U_{\text{seller}} = Q \times (\text{VWAP} - 0.08)$$
$$13.568600 = 121.611449 \times (\text{VWAP} - 0.08)$$
$$\text{VWAP}_{\text{implied}} = \frac{13.568600}{121.611449} + 0.08 = 0.111573 + 0.08 = \mathbf{0.191573\text{ AUD/kWh}}$$
However, Strategy A's actual clearing VWAP across the 1,752 hours is **$0.219934 AUD/kWh**. Clearing at $\$0.219934\text{ AUD/kWh}$ yields an implied seller benefit of:
$$U_{\text{seller}} = 121.611449 \times (0.219933811 - 0.08) = \mathbf{17.01755349\text{ AUD}}$$

Similarly for Strategy B:
$$\text{VWAP}_{\text{implied}} = \frac{16.422774}{121.611449} + 0.08 = \mathbf{0.215043\text{ AUD/kWh}} \neq \mathbf{0.271490\text{ AUD/kWh (actual)}}$$
And for Strategy C:
$$\text{VWAP}_{\text{implied}} = \frac{8.066497}{121.611449} + 0.08 = \mathbf{0.146330\text{ AUD/kWh}} \neq \mathbf{0.171257\text{ AUD/kWh (actual)}}$$

### 5.2 Forensic Trace of the Drafting Error
A search of the conversation transcript logs identified the exact moment these figures entered the documentation:
1. **Creation of `build_report.py` (Step 738):**  
   In Step 738, an auxiliary script was created to compile `reports/phase8d_fairness_analysis.md`. Instead of reading `df_comp["total_seller_benefit_aud"]` and `df_comp["total_buyer_benefit_aud"]` from `reports/phase8d_strategy_comparison.csv`, the script author manually populated a static Markdown template string with preliminary draft numbers.
2. **Deconstruction of the Draft Split:**  
   Cross-examining the draft numbers against individual household payoffs revealed that the author had treated `H001` purely as a seller, `H003` purely as a buyer, and arbitrarily partitioned `H002`'s surplus into seller and buyer portions:
   - For Strategy A:
     $$\text{Draft Seller} = H001 + 5.155569 = 8.413031 + 5.155569 = 13.568600\text{ AUD}$$
     $$\text{Draft Buyer} = H003 + 5.934442 = 7.251477 + 5.934442 = 13.185919\text{ AUD}$$
     $$\text{Sum of Partitioned H002} = 5.155569 + 5.934442 = 11.090011\text{ AUD} = H002_{\text{total}}$$
3. **Pristine State of Underlying Simulation Data:**  
   The actual simulation execution engine (`src/game/phase8d_evaluation.py`) generated `reports/phase8d_strategy_comparison.csv` and `reports/phase8d_hourly_selection.csv` with the **exact, uncorrupted, transaction-grounded values** from the very beginning:
   - Strategy A Seller: **\$17.017553 AUD**
   - Strategy A Buyer: **\$9.736965 AUD**
   - Strategy B Seller: **\$23.287341 AUD**
   - Strategy C Seller: **\$11.097911 AUD**
   - Strategy D Seller: **\$16.179308 AUD**
   - Strategy E Seller: **\$16.608172 AUD**

### 5.3 Diagnostic Verdict
The discrepancy was **NOT** an algorithm defect, **NOT** an incorrect aggregation, and **NOT** a data mismatch between runs. It was strictly a **stale / erroneous hardcoded Markdown table template in `build_report.py`** that bypassed the authoritative CSV. The report has been updated to reflect the true simulation CSV, which has now been independently verified against the raw bilateral transactions.
